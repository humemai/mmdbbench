# Engines

!!! note "Generated page"
    This page is generated from the result rows and the override registry, and is not edited by hand. It has not been generated from the 2026-11 rows yet.

For every engine in every lane, this page will state what we run: the version, the container image digest where a row records one, the durability classes measured, the tiers, every setting a row carries, and each override of an engine's default with the reason. Everything will be read from the result rows and the override registry, so it cannot drift from what was measured. The rules these settings follow are on the [Methodology](methodology.md) page.

Rows of the 2026-11 instrument have landed and are on the [project page](https://humem.ai/research/mmdbbench), but this page has not been generated from them yet, because the row log it reads is kept on the benchmark host. The page is generated by [`experiments/gen_engines_doc.py`](https://github.com/humemai/mmdbbench/tree/main/experiments/gen_engines_doc.py) in this repository from the clean rows of the 2026-11 instrument (the newest clean row of each cell, on the serial CPU set), together with the failed cells, which are listed as the result they are. It replaces this text when it is first generated. The earlier 2026-10 instrument was a development version; its rows were never published as a comparison and are not shown.
